Sign-ups are closed. Now make the group and send everyone their link.
  1. In WhatsApp, create the group with only Alexandre and William, then make them admins.
  2. Group info → Group settings: turn ON Approve new members, and set Add other members to Only admins.
  3. Group info → Invite to group via link → Copy link.
  4. Paste it below and tap Save. Students never see it directly.
  5. Tap Send group link to everyone. Each person on the list gets their own one-time link by email.
  6. Approve the join requests in WhatsApp. Anyone you don't recognise from the list: reject.
